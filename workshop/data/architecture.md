# Northstar AI architecture brief

Northstar AI is evaluating the fictional platform Meridian AI for its internal
research assistant. Meridian AI can run in a private VPC deployment. The company
prefers private deployment for customer documents. A pilot can integrate with
Northstar's existing Python services using an HTTP API.

The architecture team has not validated production throughput or disaster
recovery. A pilot must measure both before any company-wide commitment.
